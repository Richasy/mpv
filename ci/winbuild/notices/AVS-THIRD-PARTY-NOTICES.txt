AVS decoder components in the Windows libmpv build
==================================================

davs2
-----

Source: https://github.com/xatabhk/davs2-10bit.git
Revision: 21d64c8f8e36af71fc7a488cd6f789c86cdd1200
License: GNU General Public License version 2 or later.

The build selects a static, position-independent, CLI-free bit-depth-10
configuration. This configuration supports the AVS2 8-bit and 10-bit paths
consumed by FFmpeg's libdavs2 wrapper.

The patches below are byte-for-byte copies from
https://github.com/DanielZhang17/ffmpeg-mmt-avs.git at revision
6788d317a3a67c44f799d02c4ff83f95d6b10165. That repository declares the
GNU General Public License version 3 in its top-level LICENSE file.

The x86_64 build applies patches 0001 and 0010 and retains the NASM path.
The Windows ARM64 build applies patches 0001 through 0010 plus 0012. It
disables handwritten assembly that is not available for this fork while
retaining the patched AArch64 NEON intrinsics and Windows-safe setjmp path.
The corresponding patch files are distributed in `ci/winbuild/packages` at
the mpv source revision recorded in `build-info.txt`.

uavs3d
-------

Source: https://github.com/uavs3/uavs3d.git
Revision: 0e20d2c291853f196c68922a264bcd8471d75b68
License: BSD 3-Clause. See UAVS3D-BSD-3-Clause.txt.

The static build uses COMPILE_10BIT=ON, which includes both 8-bit and 10-bit
AVS3 decoding paths. The x86_64 build retains its SIMD sources. The Windows
ARM64 build selects the portable C path because the upstream AArch64 assembly
uses ELF directives that are incompatible with Windows COFF objects. ARM64
portable-C UHD throughput has not been established.

The Windows ARM64 portability patch is copied from the same
DanielZhang17/ffmpeg-mmt-avs revision:

06e999884317732470a1598b9a875c98aafe202f2220ea7dce3ba25f7365d053

Combined build and verification scope
-------------------------------------

FFmpeg source: https://github.com/Richasy/FFmpeg.git
FFmpeg revision: 026ddd08e6f80db6251cbb32d011c23c49470713

FFmpeg is configured with --enable-gpl, --enable-version3,
--enable-libdavs2, and --enable-libuavs3d. GPL-2.0.txt and GPL-3.0.txt
contain the applicable license texts.

The build fails unless FFmpeg reports both decoder registrations and the
static libavcodec archive defines both wrapper symbols. Those checks prove
configuration, compilation, and registration only. They do not prove that a
particular stream decodes correctly or establish decoder performance.

No AVS sample stream is redistributed. Runtime checks must use a caller-owned
or otherwise rights-controlled sample supplied outside the build artifacts.
